Privacy Policy

Last updated: August 23, 2026

nineCat Draft Sync is a Chrome extension that synchronizes completed Yahoo Fantasy Basketball draft picks with nineCat. The extension is designed to use only the information necessary to provide that draft-sync functionality.

Information the extension accesses

The extension may access information needed to operate the draft sync, including:

  • completed Yahoo Fantasy Basketball draft picks shown on the draft page;
  • nineCat draft-board information needed to keep the board synchronized;
  • browser tab information needed to detect and communicate with Yahoo Fantasy and nineCat tabs; and
  • extension settings and synchronization state stored locally in Chrome.

How this information is used

This information is used only to detect completed draft picks, synchronize those picks with nineCat, display connection and synchronization status, and remember extension settings such as whether auto-sync is enabled.

Data collection and sharing

nineCat Draft Sync does not sell user data, use user data for advertising, share user data with data brokers, or use browsing activity for purposes unrelated to the extension's draft-sync functionality.

Local storage

The extension may store draft synchronization state and user preferences using Chrome's extension storage. This information is used only to support the extension's functionality.

Website access

The extension is designed to access only Yahoo Fantasy Sports and nineCat pages required for the synchronization workflow. It is not intended to monitor unrelated browsing activity.

Remote code

nineCat Draft Sync does not download or execute remotely hosted JavaScript or WebAssembly. All extension code is packaged with the extension.

Changes to this policy

This policy may be updated if the extension's functionality or data practices change. The current version will always be posted on this page.

Contact

For questions about this privacy policy or nineCat Draft Sync, contact ninecat.support@gmail.com.
